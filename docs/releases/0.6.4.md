# StoreAdOps Claude package 0.6.4

## Scope and provenance

Updates get-started, daily-profit-brief and performance-review from the canonical
StoreAdOps Agent Skills build. Their published files must match the generated
Claude skill files byte for byte, including the existing host overlay. The
campaign-draft skill and reference are unchanged from 0.6.3. Only the selected
skill files are exported; private staging manifests and endpoints are not copied.

The guidance discovers the live operation contract before requesting
`account.verify` or `shopify.orders` with `view="report"`. Older servers remain
usable with explicit coverage limitations. Exact order count is not revenue
coverage; processed-order product subtotal is not Shopify net sales or profit.
Current-day rows are not a completed reporting period. Fixed-offset TikTok dates
are not silently treated as daylight-saving Pacific dates. Report-job permission
covers only the named account, dates, supported types and maximum job count.

This release does not change OAuth, the production ads-v3 endpoint, tools,
campaign execution, payment settings, package license, branding, or the submitted
OpenAI package. GitHub publication and directory approval remain separate facts.

## Release checks

Required before publication: canonical build/check; selected generated-file
parity; secret-pattern scan; strict Claude root/plugin validation; skill
frontmatter validation; a fresh GitHub installation; production OAuth connection
and a bounded read-only MCP probe. Record the actual outcomes below; static
checks are not conversation-level E2E or marketplace acceptance.

- Canonical build/check passed: 42 guidance scenarios, current generated output
  and 52 tooling tests. These checks do not establish model behavior.
- The three exported skills exactly match the generated Claude files; all three
  pass frontmatter validation. Strict root/plugin manifest validation passes.
- A scoped scan of 22 text files found no secret/identifier patterns or broken
  local links. The intentional public support address is allowlisted.
- Fresh GitHub installation, production OAuth/read-only checks and the server
  deployment are pending. Do not infer their success from the checks above.
