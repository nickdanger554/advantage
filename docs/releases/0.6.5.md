# StoreAdOps Claude package 0.6.5

## Scope and authorization

The owner authorized updating all four Claude skills, incorporating PR #4's
privacy-policy fix, testing without spending, and merging/releasing this
package. No backend deployment, ad execution, billing/OAuth change, new
submission, or OpenAI package publication is part of this release.

The four portable skills are built from canonical `skills-src/` in the private
StoreAdOps Agents source, with the existing Claude overlay. Only generated
skill files are exported. The public production endpoint, icon and MIT license
are preserved; private staging manifests are never exported.

The previous public version 0.6.4 instructed agents to call generic dispatchers
and request operation contracts. Production now advertises named actions and
complete schemas. This release updates call envelopes, readiness parameters,
provider/profile selectors, distinct report start/poll effects, unchanged
execution-payload binding, confirmation/idempotency and readback. Reporting
coverage, current-day, timezone and missing-profit safeguards are retained.
Skills/manifests are versioned 0.3.0; the public plugin/marketplace are 0.6.5.

The manifest declares `privacyPolicyUrl=https://app.storeadops.ai/privacy`.
The existing PNG's informational `ASSETS_PASSED_UNREAD` note is not an image
rejection; it remains unchanged.

## Reproducible checks

Canonical source: run `make build` and `make check`, then the scoped
`tooling.export_claude_release` exporter. Public package:

```bash
python -m unittest discover -s tests -v
npx --yes --package @anthropic-ai/claude-code@2.1.289 claude plugin validate --strict .
npx --yes --package @anthropic-ai/claude-code@2.1.289 claude plugin validate --strict storeadops
```

`tests/fixtures/named-contract.json` records the exact server source pin and
advertised names. `scripts/capture_contract.py --server-root PATH` captures
the relevant complete JSON schemas from that same local server checkout.
This is offline; no provider call or credential lookup is performed.
The fixtures and tests are outside the installed plugin.

Static schema tests are not proof of model behavior, live provider access or
marketplace approval. Runtime account/feature gates still apply. Keep exact
host/install, bounded live read/preview, independent synthetic behavior and
directory-scan results separate in the final release evidence.

## Rollback

Previous public baseline: 0.6.4 at
`bf8161c58038d2df04c20ef8a1c924f7ec671f76`. Revert only a demonstrated regression
in a reviewed change and publish a higher version. Do not restore obsolete
dispatcher instructions, remove the privacy declaration or rewrite tags.

## Official metadata reference

Anthropic documents the directory-only `privacyPolicyUrl` in
[plugin.json](https://code.claude.com/docs/en/plugins-reference#directory-listing-fields),
not in a marketplace entry. Strict validation requires a CLI version that
recognizes the field; do not delete it to accommodate an obsolete validator.
