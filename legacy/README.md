# Legacy, non-distributed workflow

The preserved growth-action-graphs skill targets `storeadops-mcp@1.0` and V1
capability packs. It is outside the `storeadops` plugin directory, is not loaded
or submitted with the ads-v3 plugin, and must not be represented as an ads-v3
feature. Its original source and references are retained for a future explicit
migration, without changing the MCP server or authorizing any provider action.
